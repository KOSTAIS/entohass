# Entopizo GPS Tracking for Home Assistant

Custom integration for the [Entopizo](https://entopizo.com) GPS tracking platform, built on the
[Entopizo REST API](https://entopizo.com/api_documentation/) (`https://go.entopizo.gr/api`).

## Features

For every tracker on your account you get one Home Assistant device with:

| Entity | Source |
| --- | --- |
| `device_tracker` (GPS) with address, speed, course, altitude attributes | `get_devices` → `lat`, `lng` |
| Speed, Course, Odometer, Address, Status, Last update, Stop duration, Altitude (disabled by default) | `get_devices` |
| Connectivity and Moving binary sensors | `get_devices` → `online`, `speed` |
| One sensor per platform sensor (battery voltage, fuel, temperature, driver, …) | `get_devices` → `sensors[]` |
| One binary sensor per on/off platform sensor (ignition, doors, …) | `get_devices` → `sensors[]` |

Numeric platform sensors such as `"12.6V"` are split into a value (`12.6`) and a unit (`V`), so they get history
graphs and statistics.

Speed and odometer follow your account's unit setting (km or miles).

### Events

New events from your Entopizo alert rules (overspeed, geofence in/out, ignition, SOS, …) are fired on the Home
Assistant event bus as `entopizo_event`:

```yaml
automation:
  - alias: Truck overspeed
    triggers:
      - trigger: event
        event_type: entopizo_event
        event_data:
          type: overspeed
    actions:
      - action: notify.mobile_app_phone
        data:
          message: >
            {{ trigger.event.data.device_name }}: {{ trigger.event.data.message }}
            ({{ trigger.event.data.speed }} km/h) at {{ trigger.event.data.address }}
```

Event data: `event_id`, `device_id` (Entopizo id), `device_name`, `type`, `message`, `speed`, `latitude`,
`longitude`, `address`, `time`.

Events are only generated by Entopizo when a matching alert rule is active on the platform. Only the first page of
`get_events` is read on each poll, so a very large burst of events between two polls may be partly skipped.

### Action: `entopizo.send_command`

Sends a GPRS command (`send_gprs_command`) to a tracker and returns the API response.

Only Home Assistant **administrators** can call this action; it is refused for other users.

```yaml
action: entopizo.send_command
data:
  device_id: <Home Assistant device id of the tracker>
  command_type: custom
  data: setdigout 1
response_variable: result
```

> **Warning:** immobilizer / engine-stop commands physically affect the vehicle. Protect any automation or
> dashboard button that calls this action with a confirmation step.

## Installation

### HACS (custom repository)

1. HACS → ⋮ → *Custom repositories* → add `https://github.com/KOSTAIS/entohass`, category *Integration*.
2. Install **Entopizo GPS Tracking** and restart Home Assistant.

### Manual

Copy `custom_components/entopizo` into your Home Assistant `config/custom_components/` folder and restart.

## Configuration

*Settings → Devices & services → Add integration → Entopizo GPS Tracking*, then sign in with your
go.entopizo.gr email and password.

The password is used once to obtain the `user_api_hash` token and is **not stored**; only the token is saved. If the
token is revoked (for example after you change your password), Home Assistant asks you to re-authenticate.

Options (*Configure* on the integration):

- **Update interval**: polling interval in seconds (default 60, min 15). Lower values mean more API calls; the API
  answers `429` when rate limited.
- **Fire entopizo_event**: turn the event relay on or off.

## Notes

- API timestamps are in the account's timezone; the integration assumes it matches Home Assistant's timezone.
- Location data is personal data. The diagnostics download uses an allow-list and contains no token, email,
  device names or ids, coordinates, addresses, sensor values, IMEI/SIM/VIN or driver details.
- The API token is sent as a query parameter (the API requires it). It is kept out of log and error messages,
  and redirects are never followed, so the token or password cannot be forwarded to another host.
- Like every Home Assistant integration, the token is stored unencrypted in `.storage/core.config_entries`;
  protect your Home Assistant backups. Changing your Entopizo password revokes the token.
